Spherical-Mode Workflow Guide

Spherical-mode network models: how to use the workflows

Each block says what the step accomplishes and lists the scripts and functions to use. Run the MATLAB scripts after editing their USER SETTINGS block; the functions in the bullets are called by those scripts.

1. From a full-wave simulation to a network model

Pick the column for your solver and antenna. Every column ends in the same Touchstone file of feed, internal and dominant mode ports, which the rational fit and both circuit simulators use.

  • ReadFEKOout — port, apothem, symmetry
  • ReadFE_spherical — .efe / .hfe
  • ReadFF_spherical — .ffe
  • ReadSphModes_freqs — .sph (Q)

  • general_vector_spherical_modes_FEKO.m
  • …_FEKO_Qonly.m — .sph only
  • compute_mode_coeffs_nearfield / _farfield / _Q
  • gradYlm, Spherical_Mode_Field

Every mode-expansion script writes output/SnP/S_dom_*_<antenna>.sNp: the feed and internal ports first, then the dominant TM/TE modes (named TM_L<l>_M<m>). FEKO files without a mesh ask for the antenna apothem.

2. Build and simulate the link in Keysight ADS

Run in the ADS Python console, top to bottom. The equation cells are built once per workspace; the antenna cells and the link schematic are built for each pair of Touchstone files.

Regenerate the equation tables (only if changed)

  • mathematica/LegendreFThetaFPhi.wl
  • rotation3D.wl, spherical_coordinate_transform.wl
  • vector_field_spherical_coordinate_transform.wl

→ mathematica/tables (included in the repo)

Open the workspace and load the scripts

  • start_console.py — set WORKSPACE_PATH
  • run_script("…")

Build the harmonic and rotation equation cells (once)

  • main_rebuild_gradYlm_data.py — runs the four below
  • create_Fdata_vars, create_Fdata_prime_vars
  • create_gradYlm_vars, create_gradYlm_vars_prime
  • create_rotationmat_vars, create_vector_field_rotation_vars

Build the antenna cells (Touchstone or rational fit)

  • create_snp_dual_view_cells.py — create_snp_component_cell
  • fix_rational_fit_netlist.py, then File ▸ Import ▸ Netlist
  • redraw_symbol_for_imported_cell
  • rebuild_snp_cells.py — refresh later

Build the Tx-to-Rx link schematic

  • create_tx_rx_link.py — feed + modes
  • create_tx_rx_link_internal_ports.py — with load ports
  • …_internal_ports_TRANSIENT.py — transient
  • create_vcvs_tx_gain, create_cccs_rx_aperture — loaded automatically

Prepare transient excitations and simulate

  • cst_to_ads_mdf.m, generate_mdf — CST port signals → MDF
  • generate_user_excitations.m
  • ook_cst_to_ads_mdf.m — OOK
  • Simulate in ADS; export the data display to CSV

The excitation scripts are in validation/cst_ads/time_signals/; generate_mdf is in matlab/io/ads. With internal load ports the antenna cell must have one reference pin per port. inspect_design.py prints a schematic's contents.

3. Build and simulate the link in Simulink

The builder makes an RF Blockset model by default ('Platform','simscape' for Simscape). Each workflow script below calls it with its own settings.

Define the excitations

  • generate_user_excitations.m
  • CST port V/I exports — importCSTSignal
matlab/simulink

Build the spherical-mode link model

  • build_tx_rx_link_simulink — Tx–Rx or 'TxOnly'
  • link_update_gains — new r, θ, φ without rebuilding

→ output/simulink/<model>.slx + _vars.mat

Simulate a Tx-to-Rx link at distance r

  • matlab/workflows/run_tx_rx_link_simulink.m

plots Vθ, Vφ and the Rx feed voltage

Radiated field of a pulse-driven transmitter

  • matlab/workflows/run_tx_radiated_simulink.m
  • simulinkRadiatedField — cached per direction

r·Eθ(t), r·Eφ(t), e.g. Gaussian sine

On-off keying with a switch at the internal port

  • matlab/workflows/ook/run_ook_simulink_rf.m
  • ook_load_excitation, ook_observation_loop

Compare with CST and ADS

  • validation/simulink/compare_simulink_ADS_CST.m

Compare radiated fields

  • validation/cst_ads/time_signals/compare_radiated_fields.m

Compare OOK with CST and ADS

  • validation/simulink/ook/compare_ook_CST_ADS_simulink.m

Simulink solver: ode45 for linear links, ode15s with the OOK switch; the RF circuit steps at MaxStep (default Nyquist/6) either way. OOK can also use the stored rational fit (rf_fit = "file", the _Rfit.mat from section 1).
