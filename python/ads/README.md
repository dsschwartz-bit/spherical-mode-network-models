# Keysight ADS scripts

Python scripts for the Keysight ADS Python console that turn spherical-mode
Touchstone (SnP) models into ADS schematics: equation cells for the spherical
harmonic gradients and the antenna rotation, antenna cells (SnP or rational
fit), mode-to-field VCVS / CCCS blocks, and a complete Tx-to-Rx link.

All scripts are run with `exec()` inside the console; none are standalone
programs. Most define a function that you then call; the `*_vars.py` scripts
build their cell immediately.

## Prerequisites

- Keysight ADS with the Python design-environment console
  (Tools > Python Console, or Ctrl+Shift+P).
- An ADS workspace (create it in ADS first).
- The equation tables in `mathematica/tables/` (generated by the `.wl` files
  in `mathematica/`; copies are included in the repository).
- SnP files from the MATLAB workflows (`matlab/workflows/general_vector_spherical_modes_*.m`),
  with `! Port[N] Name` header comments and mode ports named
  `TM_L{l}_M{m}` / `TE_L{l}_M{m}` (negative m written `Mneg{|m|}`).
  For rational-fit antenna cells, also the SPICE netlist from
  `matlab/workflows/generate_rationalfit_spice.m`.

## Order of use

### 1. Start the console session

Set `WORKSPACE_PATH` in the USER SETTINGS block of `start_console.py`, then:

```python
exec(open(THIS_SCRIPT_PATH := r"<repo>\python\ads\start_console.py").read())
```

This defines `SCRIPT_DIR`, `REPO_DIR`, `DATA_DIR` (= `<repo>/mathematica/tables`)
and `run_script(name)`, which runs any other script in this folder.

### 2. Generate the Mathematica-derived variable cells (once per workspace)

Create the library `Rotation_lib` in the ADS GUI first
(`SphericalHarmonics_lib` is created automatically by step 2a).

| Step | Script | Creates | Needs |
|------|--------|---------|-------|
| 2a | `create_Fdata_vars.py` | `SphericalHarmonics_lib:Ftheta_Fphi_vars` | `FTheta/FPhi_ADS_Discrete.txt` |
| 2b | `create_Fdata_prime_vars.py` | `SphericalHarmonics_lib:Ftheta_Fphi_vars_prime` | 2a library |
| 2c | `create_gradYlm_vars.py` | `SphericalHarmonics_lib:GradYlm_vars` | 2a |
| 2d | `create_gradYlm_vars_prime.py` | `SphericalHarmonics_lib:GradYlm_vars_prime` | 2b |
| 2e | `create_rotationmat_vars.py` | `Rotation_lib:RotationMatrix_vars` | `Rotation_ADS_Equations.txt` |
| 2f | `create_vector_field_rotation_vars.py` | `Rotation_lib:VectorFieldRotate_vars` | 2e, `Cart2Sph_ADS_Equations.txt` |

```python
run_script("main_rebuild_gradYlm_data.py")   # runs 2a-2d in order
run_script("create_rotationmat_vars.py")
run_script("create_vector_field_rotation_vars.py")
```

Re-running a script deletes and rebuilds its cell. After running, check in Component Options that each VAR has
Global scope (`set_global_scope()` does not always persist), and create
symbol views for `GradYlm_vars`, `GradYlm_vars_prime` and `RotationMatrix_vars`
if ADS has not done so.

### 3. Build the antenna (SnP / rational-fit) cells

```python
run_script("create_snp_dual_view_cells.py")
create_snp_component_cell(r"<repo>\output\SnP\S_dom_psi_<antenna>.s6p")
```

This builds `<base>_TOUCHESTONE`, wrapping the native SnP component. For a
rational-fit cell with the same pins:

1. `run_script("fix_rational_fit_netlist.py")` and
   `fix_rational_fit_netlist(ckt_path, snp_path)` renames the netlist nodes to
   the SnP port names (skip if this was already done in MATLAB by
   `matlab/snp/rationalfit/fix_rational_fit_netlist.m`).
2. In the ADS GUI: File > Import > Netlist File (Dialect "Spice 3", Output
   Format "ADS Netlist"). Keep the imported cell name.
3. `redraw_symbol_for_imported_cell(library, cell)` redraws its symbol to
   match the SnP pin layout.

`rebuild_snp_cells.py` (`rebuild_snp_cells(snp_paths, ...)`) refreshes these
cells later, for example after regenerating the SnP file or the fit.

### 4. Tx VCVS and Rx CCCS blocks

```python
run_script("create_vcvs_tx_gain.py")       # {antenna}_VCVS_TxGain   (needs GradYlm_vars_prime)
run_script("create_cccs_rx_aperture.py")   # {antenna}_CCCS_RxAperture (needs GradYlm_vars)
create_vcvs_tx_gain(r"<repo>\output\SnP\S_dom_psi_<tx_antenna>.s6p")
create_cccs_rx_aperture(r"<repo>\output\SnP\S_dom_psi_<rx_antenna>.s6p")
```

The link scripts in step 5 load these two files and call both functions
themselves, so running them by hand is only needed to build or inspect the
blocks on their own.

### 5. Build the link schematic

| Script | Function | Use |
|--------|----------|-----|
| `create_tx_rx_link.py` | `create_tx_rx_link(tx_snp, rx_snp, ...)` | S-parameter link; antennas with a single "Feed" port plus mode ports |
| `create_tx_rx_link_internal_ports.py` | `create_tx_rx_link_internal_ports(tx_snp, rx_snp, ...)` | as above, for antennas with internal (load) ports and per-port references |
| `create_tx_rx_link_internal_ports_TRANSIENT.py` | `create_tx_rx_link_internal_ports_TRANSIENT(tx_snp, rx_snp, ...)` | internal-ports link with an added transient analysis (causal delays) |

```python
run_script("create_tx_rx_link.py")
create_tx_rx_link(r"<repo>\output\SnP\S_dom_psi_<tx_antenna>.s6p",
                  r"<repo>\output\SnP\S_dom_psi_<rx_antenna>.s6p")
```

Each link script loads `create_vcvs_tx_gain.py`, `create_cccs_rx_aperture.py`
and `create_snp_dual_view_cells.py`, uses the rational-fit antenna cell when it
exists (otherwise `<base>_TOUCHESTONE`), and needs the cells from step 2.

## Utilities

- `inspect_design.py`: `inspect_design((library, cell, view), to_file=False)`
  prints a design's instances, parameters and nets; with `to_file=True` it
  writes `<repo>/output/ads/<library>_<cell>_<view>.txt`.
- `fix_rational_fit_netlist.py`: pure Python, also usable outside ADS.
